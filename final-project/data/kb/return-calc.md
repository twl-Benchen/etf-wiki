# 報酬的算法

## 一句話解釋

本系統目前顯示的都是價格報酬，也就是只看股價變化，沒有把配息加回來。

## 本系統的算法

- 區間報酬：期末收盤價除以期初收盤價再減一。期初如果不是交易日，取之前最近的一個交易日。
- 年化報酬：把一年以上的累積報酬換算成平均每年的複利報酬。
- 所有數字都由程式依價格資料計算，語言模型只負責說明，回答中的數字是用編號填入的。

## 價格報酬和總報酬

- 總報酬是把配息加回去之後的報酬，比價格報酬高。
- 配息越多的 ETF，兩者的差距越大，所以用價格報酬比較高股息型和市值型 ETF，會低估高股息型。
- 等配息資料整理完成後，系統才會提供含息的報酬。

## 股票分割

ETF 分割 (例如一拆四) 會讓股價變成原來的幾分之一，但持有的單位數變多，資產不變。計算報酬前，價格要先換算成同一個基準。
