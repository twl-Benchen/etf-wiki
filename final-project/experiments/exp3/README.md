# 實驗三：截圖辨識的可行性測試

比較兩種方法把券商庫存截圖讀成持股清單的正確率：傳統 OCR (文字辨識加規則) 與看圖模型 (Groq `qwen/qwen3.8-27b`)。
張數有限 (目標 20 到 30 張)，定位為「不同券商截圖的欄位辨識可行性測試」，不代表能適用所有券商。

## 步驟
1. **收集**：請提供者同意後，取得不同券商 App 的庫存截圖。放進 `experiments/exp3/images/` (這個資料夾在 .gitignore 裡，不會上傳)。
2. **去識別化**：先用任何修圖工具把姓名、帳號塗黑，檔名改成 `b01_券商代號.png` 這種不含個資的名稱。
3. **標準答案**：複製 `gold_template.csv` 成 `gold.csv`，每張圖每一檔持股一列，手動填代號、股數、成本均價、市值 (圖上沒有的欄位留空)。
4. **跑看圖模型**：`GROQ_API_KEY=... python experiments/exp3/run_vision.py`，結果存在 `pred_vision/`。
5. **跑傳統 OCR**：`python experiments/exp3/run_ocr.py` (需要安裝 tesseract 與繁中語言包 `chi_tra`)，結果存在 `pred_ocr/`。
6. **評分**：`python experiments/exp3/evaluate.py`，輸出 `report.md`。
7. **刪除原圖**：測試完把 `images/` 刪掉，只保留 `gold.csv` 和辨識結果 (不含個資)。

## 指標
- 代號正確率：標準答案中的每一檔，有沒有被讀出來 (以代號比對)
- 股數、成本、市值的欄位正確率：代號對上的持股中，欄位值相符的比例 (股數要完全相同；成本允許 0.1%、市值允許 0.5% 誤差)
- 整張完全正確的比例
- 多讀的列數 (讀出標準答案沒有的代號)
