# Demo 流程 (期末報告用，約 5 分鐘)

展示前：打開後端網址把免費的 Space 叫醒，再打開城市網頁，確認左上角顯示「已連線後端｜LLM Agent」。連不上時城市會自動用離線模式，流程一樣可以走完。

操作：WASD 走路、拖曳轉頭、Shift 跑步、F 騎滑板車 (Shift 加速)、V 切換背後視角和眼睛視角、M 導覽圖；手機用左下搖桿和右上的「滑板車」按鈕。點店家會自動走過去並打開店家卡片。

| 順序 | 操作 | 要讓大家看到的重點 |
|---|---|---|
| 1 | 打開城市，先轉身看廣場大螢幕，再走到對面的台積電旗艦店 | 每家店是一家公司 (市值前 100 大)，同產業在同一條街，店面越寬市值越大；地上的彩色導引線是 ETF，櫥窗貼紙是持有它的 ETF；天氣是大盤 |
| 2 | 問「今天城市怎麼了？」 | 回答和導覽圖同時出現：每家店依漲跌上色；大跌的店拉下一半鐵捲門、大漲的掛彩帶 |
| 3 | 問「0050 跟 00878 差在哪？」 | 地上只留下兩條導引線，角色自動走到兩檔都持有的店，門口有光柱；打開「Agent 執行過程」看 Planner 的 JSON 計畫、工具結果、編號數字與數字檢查 |
| 4 | 問「每月 5000 買 0050，從 2020 到現在會怎樣？」 | 逐月回放，廣場大螢幕和下方走勢圖顯示投入與市值，大跌的月份下雨 |
| 5 | 接著問「換成 00878 呢？」 | Agent 記得上一題的金額與起始時間 |
| 6 | 按「我的持股」，上傳一張已去識別化的截圖 (或直接用預設金額) → 計算 | 看圖模型讀出持股，確認後才計算；店門口的金色購物袋是實際持有比例，台積電特別大 |
| 7 | 問「00878 最近換股換了什麼？」 | 新進前十大的店門口亮起綠色光柱 |
| 8 | 問「什麼是收益平準金？」 | RAG 從 ETF 入門 Wiki 檢索，回答附來源 |
| 9 | 問「0056 明天會漲嗎？」 | 拒答，並改給可以查證的歷史資料 |
| 10 | 打開 Gradio 介面 | 同一題在 Gradio 上看完整的規劃、草稿、退回重寫的紀錄 |

可以準備的備案：截圖辨識失敗時改手動輸入金額；後端休眠時用離線模式說明「數字都是程式算的，LLM 只負責規劃與撰寫」。
