- **只有人能修改 raw/**，AI 只能讀。AI 查到的補充資訊寫在 `wiki/sources/` 的來源摘要頁。
- 卡片裡的「重點筆記」是人用白話整理的摘要，不是原文。Ingest 時一定要讀卡上的原文連結，不能只靠卡片。
- 想保留原文 PDF 的話放在 `raw/_originals/`，這個資料夾不會上傳 GitHub。
- 每張卡的 ingest 狀態記在 `wiki/index.md` 的「來源」區。
